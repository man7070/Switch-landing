# Switch — landing page

Одностраничный лендинг маркетингового агентства Switch (Ташкент).

- `index.html` — вся страница: разметка, стили и небольшой скрипт меню
- `og.png` — картинка для превью ссылки в Telegram и соцсетях
- Все кнопки ведут в Telegram-бот: https://t.me/operator_marketing_bot

Публикуется через GitHub Pages из ветки `main`.

## Версии

- `/` — первая версия (тёмная).
- `/v2/` — вторая версия: дизайн по дизайн-коду Switch, тёмная и светлая тема с переключателем,
  расширенный контент (боли, «Marketing — bu matematika», 7 услуг, 4 шага, бесплатный аудит, вопросы).
  Пока помечена `noindex`: при переносе на главный адрес убрать этот тег и поправить `og:url`.
