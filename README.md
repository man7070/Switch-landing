# Switch — landing page

Одностраничный лендинг маркетингового агентства Switch (Ташкент).

- `index.html` — вся страница: разметка, стили и небольшой скрипт меню
- `og.png` — картинка для превью ссылки в Telegram и соцсетях
- Все кнопки ведут в Telegram-бот: https://t.me/operator_marketing_bot

Публикуется через GitHub Pages из ветки `main`.

## Версии

- `/` — первая версия (тёмная).
- `/v2/` — вторая версия: дизайн по дизайн-коду Switch, тёмная и светлая тема с переключателем,
  расширенный контент (боли, «Marketing — bu matematika», 7 услуг, 4 шага, бесплатный аудит, вопросы).
  Пока помечена `noindex`: при переносе на главный адрес убрать этот тег и поправить `og:url`.

## Стабильная версия для тестов

- `/v2.0/` — замороженная копия v2 (тег `v2.0`). Её не меняем: рекламу и тесты ведём сюда.
- `/v2/` — рабочая версия, сюда идут новые правки.

## Как отслеживается источник

Каждая кнопка ведёт в бот со стартовым параметром:
`https://t.me/operator_marketing_bot?start=lp2_<место>_<utm_source>_<utm_campaign>_<utm_content>`

- `lp2` — пришёл с лендинга v2.
- место: `hero`, `bar` (нижняя плашка на телефоне), `final`, `header`, `footer`, `panel`.
- UTM берутся из адреса страницы (остаются на всю сессию), из них вырезается всё, кроме латиницы и цифр; длина до 64 символов.
- Без UTM: просто `lp2_hero` и т. п.

Бот получает это как `/start lp2_hero_instagram_auditnoyabr_reels1`.
